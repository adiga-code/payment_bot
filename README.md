# Telegram-бот для обработки платёжных заявок

Бот автоматизирует полный цикл согласования платежей: от подачи заявки клиентом до выставления счёта и подтверждения оплаты. Каждая заявка проходит многоуровневую проверку, а все действия фиксируются в системе.

---

## Что делает бот

- Принимает платёжные заявки от клиентов через Telegram
- Проводит автоматическую проверку контрагента по ИНН (сервис «Честный Бизнес»)
- Направляет заявку по цепочке согласования: менеджер → банк → руководитель
- Контролирует лимиты компаний и банков (дневные, недельные, месячные)
- Формирует счёт на оплату в формате PDF
- Отправляет документы клиенту прямо в чат
- Ведёт полный журнал действий (кто, когда, что сделал)

---

## Роли в системе

### Клиент
Отправляет боту команду `/zayavka` и заполняет данные: сумму, ИНН плательщика, назначение платежа. Получает номер заявки и уведомления о каждом этапе обработки. После одобрения — получает счёт на оплату.

### Менеджер
Видит список входящих заявок, берёт их в работу. Проверяет данные, выбирает компанию-плательщика и банк для проведения. Может одобрить или отклонить заявку с комментарием.

### Сотрудник банка
Получает заявки, прошедшие проверку менеджера. Оценивает риски: без риска, минимальный или высокий. При высоком риске — может отклонить заявку или эскалировать руководителю.

### Руководитель
Принимает финальное решение по заявке. Может одобрить (при этом автоматически обновляются лимиты и генерируется счёт), отклонить или вернуть менеджеру на доработку. Видит эскалированные заявки отдельным списком.

### Бухгалтер
Работает с одобренными заявками: формирует счета на оплату, при необходимости перегенерирует документы, отправляет их клиенту и фиксирует факт оплаты.

### Администратор
Управляет всей системой: добавляет и удаляет пользователей, назначает роли, создаёт компании и банки, настраивает лимиты, просматривает общую статистику. Привязывает группы Telegram к банкам для групповой работы.

---

## Как проходит заявка

```
Клиент подаёт заявку
        ↓
Автоматическая проверка ИНН
        ↓
Менеджер проверяет и выбирает компанию/банк
        ↓
Банк оценивает риски
        ↓
Руководитель принимает финальное решение
        ↓
Бухгалтер формирует счёт → клиент получает PDF
```

На каждом этапе участник получает уведомление в Telegram. При отклонении клиент получает причину отказа.

---

## Система лимитов

Для каждой компании и банка настраиваются ограничения на суммы платежей:

- **Дневной лимит** — максимальная сумма за день
- **Недельный лимит** — максимальная сумма за неделю
- **Месячный лимит** — максимальная сумма за месяц (для компаний)

Лимиты автоматически сбрасываются по расписанию. Если заявка превышает остаток лимита — система предупредит об этом.

---

## Документы

Бот генерирует счета на оплату в формате PDF с полными реквизитами:
- Номер и дата документа
- Данные плательщика (название, ИНН)
- Сумма цифрами и прописью
- Назначение платежа

Документы отправляются клиенту файлом в Telegram.

## Команды бота

| Команда | Кто использует | Что делает |
|---------|---------------|------------|
| `/start` | Все | Начало работы с ботом |
| `/zayavka` | Клиент | Создать заявку на оплату |
| `/manager` | Менеджер | Открыть панель менеджера |
| `/bank` | Сотрудник банка | Открыть панель банка |
| `/supervisor` | Руководитель | Открыть панель руководителя |
| `/accountant` | Бухгалтер | Открыть панель бухгалтера |
| `/admin` | Администратор | Открыть панель управления |

## Запуск

1. Скопируйте `.env.example` в `.env`
2. Заполните переменные:
   - `BOT_TOKEN` — токен Telegram-бота (получить у @BotFather)
   - `POSTGRES_PASSWORD` — пароль базы данных
   - `ADMIN_IDS` — Telegram ID администраторов (через пробел)
   - `ZCB_API_KEY` — ключ API «Честный Бизнес» (опционально)
3. Запустите:
   ```
   docker compose up --build -d
   ```

Бот, база данных и панель управления БД (pgAdmin) запустятся автоматически.

---

## Безопасность

- Доступ к функциям строго по ролям — каждый видит только свой раздел
- Все действия записываются в журнал аудита
- Данные хранятся в PostgreSQL, пароли не хранятся (авторизация через Telegram)
- Бот работает в Docker-контейнерах, изолированных от хост-системы
